# Cultivated Care Agency — Redesign Mockup

A responsive, multi-page static website concept designed to be inexpensive to host and straightforward to recreate in Squarespace using standard sections, image blocks, buttons, cards, forms, and accordion blocks.

Open `dist/index.html` to preview locally. Replace the placeholder Google Form URLs (`https://forms.google.com`) with the agency's live intake and application links before launch.

## Structure

- `dist/index.html` — complete homepage
- `dist/services.html` — dedicated services page for families and caregivers
- `dist/about.html` — dedicated story, values, and community page
- `dist/contact.html` — dedicated contact and next-step page
- `dist/styles.css` — visual design and responsive layout
- `dist/script.js` — mobile navigation, scroll reveal, and header behavior
- `dist/assets/` — original mockup imagery
